================================================================================
GUIA DE PRUEBAS PASO A PASO - MAGNATALLER (AA01 - .NET 10)
================================================================================

ANTES DE EMPEZAR (CONFIGURACION UNICA EN CONSOLA):
1. Abre una terminal en la carpeta del proyecto:
   cd "C:\Users\pcuser\Desktop\3ro\P.Web\WEB-3BM-B1-AA01-AutenticacionSegura-ParedesRodny"
2. Configura tus credenciales SMTP reales en User Secrets (para correo de Gmail usa una "Contraseña de aplicacion"):
   dotnet user-secrets set "SmtpSettings:Servidor" "smtp.gmail.com"
   dotnet user-secrets set "SmtpSettings:Puerto" "587"
   dotnet user-secrets set "SmtpSettings:Usuario" "tu_correo@gmail.com"
   dotnet user-secrets set "SmtpSettings:Password" "tu_app_password"
   dotnet user-secrets set "SmtpSettings:Remitente" "tu_correo@gmail.com"
3. Ejecuta el proyecto (en Visual Studio con F5 o en consola con: dotnet run).

--------------------------------------------------------------------------------
PRUEBA 1: VERIFICACION VISUAL DEL LOGIN (SIN CREDENCIALES VISIBLES)
--------------------------------------------------------------------------------
1. Ingresa a la URL principal (https://localhost:7140 o http://localhost:5140).
2. Verifica que se muestra el formulario de Iniciar Sesion con la estetica de MagnaTaller (barra superior carbon #1f2428, acento naranja #e65c00).
3. RESULTADO ESPERADO: NO debe aparecer ningun cuadro ni texto con cuentas o claves de prueba en pantalla.

--------------------------------------------------------------------------------
PRUEBA 2: REGISTRO PUBLICO Y ROL AUTOMATICO DE CLIENTE
--------------------------------------------------------------------------------
1. Haz clic en "Registrarse".
2. Registra una cuenta de prueba con el correo real: ronypygg@gmail.com
   - Nombre: Rony Prueba
   - Correo: ronypygg@gmail.com
   - Clave: Cliente123!
   - Confirmar: Cliente123!
3. RESULTADO ESPERADO: Redirige al Login con mensaje de exito. No existe ninguna opcion para elegir el rol Administrador.

--------------------------------------------------------------------------------
PRUEBA 3: INICIO DE SESION, COOKIE PERSISTENTE ("RECORDARME") E INCOGNITO
--------------------------------------------------------------------------------
1. Inicia sesion con ronypygg@gmail.com / Cliente123! marcando la casilla "Recordarme".
2. Abre otra pestaña en el mismo navegador y entra a /Cuenta/Perfil.
3. RESULTADO ESPERADO: La sesion sigue abierta automaticamente (cookie .MagnaTaller.Auth con HttpOnly=true y IsPersistent=true).
4. Abre una ventana de INCOGNITO y entra a /Cuenta/Perfil.
5. RESULTADO ESPERADO: Te redirige al Login (aislamiento de sesion correcto).

--------------------------------------------------------------------------------
PRUEBA 4: PERFIL Y CAMBIO DE CONTRASENA
--------------------------------------------------------------------------------
1. Estando logueado como ronypygg@gmail.com en /Cuenta/Perfil, verifica que muestre tu Nombre, Correo, Rol ("Cliente") y Estado ("Activo").
2. En el formulario "Cambiar Contraseña", ingresa la clave actual incorrecta y una nueva.
3. RESULTADO ESPERADO: Muestra error y no cambia la clave.
4. Ahora ingresa la clave actual correcta (Cliente123!) y la nueva clave (Cliente456!).
5. RESULTADO ESPERADO: Mensaje de exito. Cierra sesion y verifica que solo puedes entrar con Cliente456!.

--------------------------------------------------------------------------------
PRUEBA 5: CONTROL DE ACCESO POR ROLES (403 ACCESS DENIED)
--------------------------------------------------------------------------------
1. Estando logueado con el rol Cliente (ronypygg@gmail.com), escribe manualmente en la barra de direcciones:
   /Admin/Usuarios
2. RESULTADO ESPERADO: El sistema bloquea el acceso y muestra la vista "403 - Acceso Denegado".

--------------------------------------------------------------------------------
PRUEBA 6: BLOQUEO TEMPORAL POR INTENTOS FALLIDOS (LOCKOUT)
--------------------------------------------------------------------------------
1. Cierra sesion.
2. Intenta iniciar sesion con ronypygg@gmail.com ingresando una contraseña incorrecta 3 veces seguidas.
3. En los intentos 1 y 2 debe decir: "Credenciales inválidas." (mensaje generico).
4. En el intento 3 (y si intentas inmediatamente con la clave correcta):
   RESULTADO ESPERADO: "Cuenta bloqueada temporalmente por intentos fallidos. Intente en 1 minuto."
5. Espera 1 minuto y vuelve a intentar con la clave correcta. Debe dejarte ingresar.

--------------------------------------------------------------------------------
PRUEBA 7: RECUPERACION DE CONTRASENA POR CORREO REAL Y TOKEN DE UN SOLO USO
--------------------------------------------------------------------------------
1. En el Login, haz clic en "¿Olvidaste tu contraseña?".
2. Ingresa ronypygg@gmail.com y envia el formulario.
3. Revisa la bandeja de entrada de ronypygg@gmail.com y haz clic en el boton "Restablecer Contraseña" del correo recibido.
4. Ingresa una nueva clave (ej. NuevaClave123!) y guarda.
5. RESULTADO ESPERADO: Contraseña actualizada. Inicia sesion con NuevaClave123! para confirmar.
6. PRUEBA DE TOKEN REUTILIZADO: Vuelve a hacer clic en el MISMO enlace del correo e intenta cambiar la clave otra vez.
7. RESULTADO ESPERADO: El sistema rechaza el enlace indicando que es invalido, ha expirado o ya fue utilizado.

--------------------------------------------------------------------------------
PRUEBA 8: PANEL ADMINISTRATIVO, CAMBIO DE ROL, DESHABILITAR Y ULTIMO ADMIN
--------------------------------------------------------------------------------
1. Inicia sesion como Administrador inicial: admin@magnataller.com / Admin123!
2. Entra a "Panel Admin" (/Admin/Usuarios).
3. Verifica que en la fila de admin@magnataller.com aparece "Último Admin protegido" y NO permite degradarlo ni deshabilitarlo.
4. En la fila de ronypygg@gmail.com, haz clic en "Deshabilitar".
5. Intenta iniciar sesion en otra ventana con ronypygg@gmail.com.
   RESULTADO ESPERADO: Bloquea el acceso con "Credenciales inválidas." porque Activo == false.
6. Vuelve al Panel Admin, habilita a ronypygg@gmail.com y haz clic en "Cambiar a Admin".
7. RESULTADO ESPERADO: Ahora existen 2 administradores activos, por lo que ambos pueden gestionarse sin dejar el sistema sin administrador.

--------------------------------------------------------------------------------
PRUEBA 9: VERIFICACION DE CIFRADO PBKDF2 EN SQL SERVER
--------------------------------------------------------------------------------
1. Abre SQL Server Object Explorer en Visual Studio -> (localdb)\mssqllocaldb -> Bases de datos -> MagnaTallerAuthDb -> Tablas -> dbo.AspNetUsers.
2. Haz clic derecho -> Ver datos.
3. RESULTADO ESPERADO: La columna PasswordHash contiene un hash cifrado (nunca texto plano) y cada usuario tiene un hash distinto gracias al salt de PBKDF2.
